# FINVORA

A premium Nigerian investment platform.

## Technology Stack
- **Frontend:** Vite, Vanilla HTML, CSS, JavaScript (ES Modules)
- **Backend/Database:** Supabase
- **Hosting:** Vercel (Hobby Plan)
- **API:** Vercel Serverless Functions (located in `/api`)

## Project Structure
- `/` : User-facing pages
- `/admin` : Administrative dashboard and management
- `/api` : Serverless backend logic
- `/src` : Core utilities and Supabase client configuration
